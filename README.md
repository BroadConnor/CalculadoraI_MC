# CalculadoraI_MC
Esto es una aplicación Movil que calcula el Indice de Masa Corporal (IMC). Solicitando su estatura y su peso. 

Descripción: 
Aplicación Android de una calculadora de Indice de Masa Corporal (IMC), que solicita datos como peso y estatura. Cambia las unidades de centimetros y kilogramos a pulgadas y libras según el sistema seleccionado (Sistema métrico o Sistema Inglés). 

Funcionalidades: 
- Cálculo de IMC
- Interfaz adaptable a la orientación
- Mensaje de evaluación del resultado
- Operaciones científicas
